Welcome to RetroLemmini!

A clone of the DMA Design game Lemmings(TM) with graphics from Lemmings For Windows 95

Instructions for installation:

Windows:

1) Copy across any levels, mods, music, player data, replays, sounds and styles
   from your existing (Super)Lemmini(Too) installation into the relevant folder
   within the "resources" folder
   
   (NOTE: "RLEditor.exe is a dedicated level editor for RetroLemmini.")
   
   (NOTE: The "docs" folder contains some useful documentation for help with
   using RetroLemmini including hotkeys, cheat codes, level formatting, etc.)
   
   (NOTE: The "app" folder contains the jpackage config that links the .exe to
   the .jar, you don't need to do anything with this)
   
   (NOTE: The "custom-runtime" folder contains a lightweight Java runtime
   that RetroLemmini needs to run, you don't need to do anything with this)
 
2) Run RetroLemmini.exe

3) Enjoy!
